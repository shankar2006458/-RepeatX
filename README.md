# 🔁 RepeatX — Smart Text Repeater

RepeatX is a fast, lightweight, and user-friendly web tool designed to generate repeated text instantly. Whether you need bulk text for testing, social media, or automation tasks, RepeatX makes it simple and efficient.

🔗 **Live Demo:**
[https://shankar2006458.github.io/-RepeatX/](https://shankar2006458.github.io/-RepeatX/)

---

## ✨ Features

* ⚡ **Instant Text Repetition**
  Generate repeated text in real-time as you type.

* 🔢 **Custom Repeat Count**
  Easily control how many times your text is repeated.

* 🧹 **Clear Button**
  Reset everything with one click.

* 📋 **One-Click Copy**
  Copy generated text instantly to clipboard.

* 🎯 **Auto Reset on Launch**
  Repeat count starts at 0 for a clean experience every time.

* 🎨 **Modern UI**
  Clean, minimal, and responsive design for smooth usability.

---

## 🚀 Use Cases

* Social media text spamming (fun or testing)
* UI/UX testing with large text blocks
* Developer testing (forms, inputs, limits)
* Messaging experiments (WhatsApp, Instagram, etc.)

---

## 🛠️ Tech Stack

* **HTML5**
* **Tailwind CSS**
* **JavaScript (Vanilla)**

No frameworks. No dependencies. Just fast and simple.

---

## 📦 How to Use

1. Enter your text in the input field
2. Set the repeat count
3. Click generate (or auto-update if enabled)
4. Copy the output instantly

---

## ⚠️ Platform Limitations

Some platforms (like Instagram, WhatsApp, etc.) may limit how much repeated text can be sent at once.
RepeatX can generate large outputs, but delivery depends on platform restrictions.
